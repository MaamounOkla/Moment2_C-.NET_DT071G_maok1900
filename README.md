## Beskrivning
Detta repository innehåller två konsolapplikationer skrivna i **C# .NET** som ingår i Moment 2 i kursen *Programmering i C#.NET*.

### Uppgift 2.1
En enklare C#-applikation some generar folktroutryck baserat på veckodag (grundläggande syntax, logik och inmatning/utmatning).

### Uppgift 2.2
En applikation som:
- Genererar en array med random heltal  
- Sorterar den med **BubbleSort**  
- Sorterar en kopia med **Array.Sort**  
- Jämför tidsåtgång med **Stopwatch**  
- Accepterar kommandoradsargument för stigande/fallande sortering:  
  - `-p 0` → stigande  
  - `-p 1` → fallande  

#### Exempel på körning:
```bash
dotnet run -- -p 0
dotnet run -- -p 1
